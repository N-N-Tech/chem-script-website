# Einmaliger Import der Website

Die Website-Dateien sind **noch nicht** in diesem Repository; bisher ist nur die Projektstruktur vorbereitet.

## GitHub Desktop (empfohlen)

1. [GitHub Desktop](https://desktop.github.com/) öffnen und das private Repository `N-N-Tech/chem-script-website` klonen (**File → Clone repository**).
2. Einmalig die zuletzt erhaltene Datei `Properties_of_Matter_Website_revised_v2.zip` entpacken.
3. **Den Inhalt** des enthaltenen Ordners `Properties_of_Matter_Website` in das lokal geklonte Repository kopieren; `README.md` aus dem Repository beibehalten. Es muss auf oberster Ebene eine `index.html` liegen.
4. In GitHub Desktop die Änderungen überprüfen, Commit erstellen (beispielsweise `Import current chemistry website`) und **Push origin**.
5. Im Chat bestätigen, dass die Dateien hochgeladen sind. Anschliessend können Änderungen direkt über die GitHub-Anbindung erfolgen.

## Veröffentlichung separat

Wir veröffentlichen die private Entwicklungsablage nicht automatisch. Vor dem Einrichten einer Vorschau legen wir fest, welche Dateien öffentlich sein dürfen. Insbesondere `source/` und die Musterlösungen sollten kontrolliert werden.
